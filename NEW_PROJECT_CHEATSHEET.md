# Шпаргалка: начало нового проекта

## Сразу после создания проекта

- [ ] Создать `AGENTS.md` с инструкциями для агента.
- [ ] Создать `PREFERENCES.md` и указать в `AGENTS.md`, что перед каждой работой агент обязан прочитать предпочтения и строго им следовать. В предпочтениях закрепить правило: постоянно поддерживать Obsidian-хранилище и сохранять в нём `CHANGELOG.md`, `README.md` и `STRUCTURED_IDEAS.md`.
- [ ] Создать `BUGS.md` для фиксации ошибок и записать в предпочтениях правило никогда его не изменять.
- [ ] Создать Obsidian-хранилище с папкой `.obsidian/`.
- [ ] Добавить в хранилище `CHANGELOG.md` и `PROJECT.md`.
- [ ] Записать в предпочтениях обязанность обновлять changelog и описание проекта при разработке.
- [ ] Создать `HANDWRITTEN_IDEAS.md` для ручных идей пользователя и запретить агенту его редактировать.
- [ ] Создать `STRUCTURED_IDEAS.md`: агент обновляет его на основе `HANDWRITTEN_IDEAS.md`, сохраняя оригинальные заметки нетронутыми.

## Правило работы с идеями

1. Пользователь вносит мысли в `HANDWRITTEN_IDEAS.md` в любом удобном виде.
2. Агент читает их, но не меняет этот файл.
3. Агент переносит понятные задачи, вопросы и приоритеты в `STRUCTURED_IDEAS.md`.
4. Выполненные изменения фиксируются в Obsidian: в `CHANGELOG.md` и, если нужно, в `PROJECT.md`.

## Правило хранения документации

Obsidian — основное место для проектной документации. Агент поддерживает актуальность `CHANGELOG.md`, `README.md` и `STRUCTURED_IDEAS.md` именно в Obsidian-хранилище, согласно `PREFERENCES.md`.
